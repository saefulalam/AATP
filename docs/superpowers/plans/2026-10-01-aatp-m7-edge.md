# AATP M7 Edge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement quarantine with scanner hooks, the untrusted-content doctrine helpers, the reference HTTP transport + relay mailbox, and MCP tool adapters — per blueprint §11, §12 (audit), §13, §16, §17.1 N21, §18.3 M7.

**Architecture:** `aatp/quarantine.py` (verdicts, release, taint), `aatp/sec.py` (model-channel delimiting, filename quoting, tool re-auth via policy), `aatp/transport/` package (`http.py` reference server, `relay.py` in-memory mailbox+chunk store), `aatp/mcp_server.py` (5 tools as pure functions + stdio JSON-RPC runner). No crypto invented; scanners are injected callables.

**Tech Stack:** Python 3.12 stdlib only for transport (`http.server`, `urllib` in tests) — no web framework, no MCP SDK. Existing `aatp/` modules reused.

**Spec:** `docs/superpowers/specs/2026-10-01-aatp-core-m0-m5-design.md`
**Blueprint:** `AATP_v0_2_Blueprint.md` §11 (SEC-001..008), §12 (AUD-001/002), §13 (NET-001..003 + HTTP reference), §16 (MCP tools), §17.1 N21, App. B (demo)

## Global Constraints

- One rule ID = one test, named after the rule ID, failing-first (§18.4.1).
- Never log or print private keys, CEKs, or plaintext artifact bytes (§18.4.2). Tests use tiny fixtures, never real secrets.
- Fail closed on ambiguity; record in `DECISIONS.md` (§0.4, §18.4.3).
- No features outside the blueprint (§18.4.4).
- Quarantine states use transfer's vocabulary: `accepted | rejected | quarantined` (RECEIPT outcomes); local quarantine record `{content_root, node_id, state, verdicts[], released_by?}`.
- Scanner verdict: `{scanner_name, scanner_version, verdict: clean|suspicious|malicious, at}` (SEC-007: verdict recorded with name/version).
- Scanner is a policy dependency, never a cryptographic guarantee (SEC-007).
- `quarantined` MUST NOT be reported as `malicious` unless a trusted subsystem established it (SEC-006).
- Filenames quoted with `shlex.quote` for shell; model channel uses fenced delimiters (SEC-005, SEC-003).
- Branch `feat/core-m0-m5`; do NOT switch branches or change git config; tests via `.venv\Scripts\python -m pytest`; PowerShell 5.1.

### Task M7-2: `transport/` reference HTTP + relay mailbox (NET-001..003, §13)

**Files:**
- Create: `aatp/transport/__init__.py`, `aatp/transport/relay.py`, `aatp/transport/http.py`
- Test: `tests/test_transport.py`
- Modify: `DECISIONS.md`

**Interfaces:**
- Consumes: `aatp.errors`, `aatp.canon`, `aatp.dsse.verify_envelope`, `aatp.seal` (packets opaque to relay — relay never opens).
- Produces (`relay.py`): `Relay` class (in-memory): `put_packet(packet: dict) -> str` (validates exact packet keys + `aatp=="0.2"` shape only, stores keyed by `to`, returns hex id = SHA256(JCS(packet)) for idempotency); `take_packets(agent_id: str) -> list[dict]` (drains mailbox for `to`); `put_chunk(transfer_id: str, index: int, data_b64: str) -> None` (idempotent overwrite); `get_chunk(transfer_id, index) -> str|None`; `put_card(card_env) / get_card(agent_id)`; size/rate guard params `max_stored_packets`, `max_chunk_bytes` (NET-002; exceeding → `ERR_SIZE_LIMIT`/`ERR_RATE_LIMIT`); relay never mutates packets (assert round-trip equality in tests, NET-002).
- Produces (`http.py`): `serve(relay: Relay, *, host="127.0.0.1", port=0) -> HTTPServer` (threaded `ThreadingHTTPServer`, stdlib only). Routes exactly: `POST /aatp/v0.2/packets` → 202 (body = packet JSON; idempotent by content hash; duplicate → 202 same id); `PUT /aatp/v0.2/transfers/{tx}/chunks/{i}` (`application/octet-stream` raw bytes; store b64; → 204; idempotent); `GET /aatp/v0.2/agents/{agent_id}/card` → 200 card JSON / 404; `GET /aatp/v0.2/mailbox/{agent_id}` requires `Authorization: DSSE <b64u(JSON-envelope)>` where the envelope payload is `JCS({"method":"GET","path":<path>,"created_at":<ts>,"agent_id":<id>})` signed by the requester's signing key, verified against `card_resolver(agent_id)` (injected); bad auth → 401/403 (map: malformed → 400, bad sig/unknown agent → 401, agent mismatch vs path → 403); record exact auth format in DECISIONS.md (§13 leaves bytes unspecified). TLS: none locally — note NET-001 (defense in depth; security MUST NOT depend on TLS) in DECISIONS.md.
